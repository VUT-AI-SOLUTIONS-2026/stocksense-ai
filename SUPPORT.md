# Support

## For the team

| What you need | Where to go |
| --- | --- |
| To understand the project | [README](README.md), then [`docs/`](docs) |
| To see what needs doing | The [project board](https://github.com/orgs/VUT-AI-SOLUTIONS-2026/projects) |
| To set up and start contributing | [CONTRIBUTING.md](CONTRIBUTING.md) |
| To report something broken | [Open a bug report](../../issues/new/choose) |
| To suggest a capability | [Open a feature request](../../issues/new/choose) |
| To report a security or data problem | Privately. See [SECURITY.md](SECURITY.md) |

## Before opening an issue

Search the existing issues first, because someone has probably hit it already. When you do open one, include the full error message rather than a description of it, say what you expected to happen, and give the exact command you ran.

## For lecturers and moderators

If you are assessing this project, the [`docs/`](docs) folder is organised to follow the marking rubric section by section, and the table in the [README](README.md#project-documentation) maps each document to its criterion and mark allocation.

The commit history and the [project board](https://github.com/orgs/VUT-AI-SOLUTIONS-2026/projects) show how the work was divided and when it was done.
