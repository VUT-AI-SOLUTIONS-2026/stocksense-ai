# Problem definition

**Rubric section:** Problem definition. **Marks: 10.**

**What is assessed:** the problem definition is factual, achievable, clearly articulated and relevant to the theme. A marker must be able to find the answers to these questions easily when reading it:

* What is the problem?
* How relevant is it to the theme?
* How beneficial will it be to solve it?

## Hard limits from the brief

These are not suggestions. The brief gives exact word counts.

| Limit | Count |
| --- | --- |
| The whole problem definition | 250 words maximum |
| The "what exactly is the problem" part | 190 words maximum |

The brief also asks the definition to answer how solving the problem with AI will benefit the local municipality or community. Do not leave that out, and remember it has to fit inside the same 250 words.

Count the words before you submit. Going over is an avoidable way to lose marks.
