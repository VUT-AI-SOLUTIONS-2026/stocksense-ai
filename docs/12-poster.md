**What is assessed:** an overview of the entire project has been nicely articulated, so that someone understands it by reading the poster.

The brief asks for a soft copy poster that sells the idea, captures the key features, and is straight to the point. Ten marks, which is the same as the whole problem definition, so it is not a decoration.

## Design notes

Straight to the point is the instruction, so treat every word as though it costs something.

* One idea per block, and plenty of empty space.
* A reader should be able to follow it without anyone explaining it.
* A simple diagram of the flow from sales data to reorder recommendation does more than a paragraph.
* Readable from a distance. If it only works when you zoom in on a laptop, it is not finished.
* Keep the colours consistent with the rest of the submission.
