- [ ] All report sections completed and reviewed.

- [ ] Background and theme relevance limited to one paragraph.
- [ ] Problem definition within 250 words; problem description within 190 words.

- [ ] Arial 12, line spacing 1.5 and justified text.
- [ ] Grammarly certificate or results included.
