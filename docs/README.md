## Formatting rules

The brief is specific, and says marks are deducted when the format is wrong. When these documents are exported for submission they must be:

* Arial, size 12
* Line spacing 1.5
* Justified text
* Checked with Grammarly, with the report included in the submission

## A warning worth repeating

The rubric notes that marks are lost where students cannot explain a section, even when all the information is there. Whoever writes a document should be able to talk through it without notes. Do not split the writing so finely that nobody understands the whole thing.
